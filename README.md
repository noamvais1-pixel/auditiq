# AuditIQ

[![CI](https://github.com/noamvais1-pixel/auditiq/actions/workflows/ci.yml/badge.svg)](https://github.com/noamvais1-pixel/auditiq/actions/workflows/ci.yml)

עוזר AI לרואי חשבון ומבקרים, שעונה **רק** על סמך מקורות במאגר ומצטט אותם ברמת
הסעיף. עברית, RTL, עם הסרת מידע מזהה לפני כל פנייה למודל ולוג ביקורת עמיד לשינוי.

בנוי סביב הנחה אחת: בסביבת ביקורת, תשובה בטוחה שאין לה מקור גרועה מאין תשובה.
כל החלטה בפרויקט נגזרת מזה.

```bash
git clone <repo> && cd auditiq
make demo          # רץ ללא מפתח API כלל
make api           # טרמינל 1
make web           # טרמינל 2  →  http://localhost:5173
```

ללא מפתח המערכת רצה במצב הדגמה: **האחזור, הסרת המידע המזהה, שער הכיסוי, אכיפת
הציטוט ולוג הביקורת פועלים במלואם**, ורק הניסוח מוחלף בציטוט ישיר מהמקורות.
כדי להריץ מול מודל אמיתי: `cp .env.example .env`, להוסיף מפתח, ו-`make ingest`.

## מה מיוחד כאן

רוב פרויקטי ה-RAG עוצרים ב"חיברתי מודל למסמכים". שלושת הדברים הבאים הם מה
שמפריד בין הדגמה לבין משהו שאפשר להכניס לתיק עבודה:

### 1. ציטוט הוא תנאי, לא בקשה

בקשה מהמודל לצטט מקורות מייצרת ציטוטים. היא לא מייצרת ציטוטים **נכונים** —
הכשל השכיח הוא מזהה תקין למראה שמעולם לא היה בהקשר, ושנראה זהה לאמיתי לכל מי
שקורא במהירות.

לכן זה נבדק מכנית אחרי היצירה ולא רק מתבקש לפניה: מזהה שלא סופק — מוסר ומדווח.
תשובה מהותית ללא ולו ציטוט תקף אחד — מומרת לסירוב, ללא תלות בתוכנה.
`0 ציטוטים מומצאים מתוך 30` בסוויטה.

### 2. סירוב כשאין כיסוי — ובשתי שכבות, כי אחת לא הספיקה

הגישה המתבקשת, סף על ציון האחזור, **לא עובדת**, וסוויטת ההערכה היא שהראתה זאת.
נמדדו BM25 גולמי, קוסינוס וחפיפת מונחים בנפרד: בכל אחד מהם השאלה שמחוץ לתחום
"מה שיעור דמי הביטוח הלאומי למעסיק" מקבלת ציון **בתוך** הטווח של שאלות
לגיטימיות. המילה "שיעור" לבדה נושאת מספיק מסה לקסיקלית.

אחרי שהגזירה העברית נכנסה **כן** נמצא סף שמפריד את כל הסט בשלמות. הוא לא בשימוש:
גבול שמכויל על שלוש דוגמאות שליליות הוא overfitting, ועלות שני סוגי השגיאה אינה
סימטרית — סירוב שגוי גורם לרואה חשבון ששאל שאלה טובה לחשוב שהכלי שבור. הספים
עומדים פי 2.5 מרווח מהשאלה הלגיטימית הגרועה ביותר, והשיפוט הסמנטי הוא תפקיד
המודל.

הסוויטה מדווחת על שתי השכבות בנפרד, ומסמנת `SKIPPED` כשאין מפתח — ריצת CI ירוקה
שמעולם לא הפעילה את השער הסמנטי גרועה מריצה אדומה.

### 3. מספרים, לא הערכות

```
                                       recall@6    MRR   paraphrase
BM25 בלבד                                 0.959   0.747        0.93
BM25 + אמבדינגס לקסיקליים מקומיים         0.890   0.691        0.87
BM25 + gemini-embedding-2                 0.993   0.891        1.00
```

שלוש מסקנות שכולן שינו את הקוד — כולל הממצא הלא נוח שהגיבוי המקומי **מזיק**
לאחזור ולכן משקלו באיחוד הוא אפס. [EVALUATION.md](docs/EVALUATION.md).

## פרטים שנבעו מהדומיין

**עברית ב-BM25.** טוקנייזר סטנדרטי שובר recall בשקט. אותיות סופיות מקופלות,
תחיליות ו/ה/ב/ל/כ/מ/ש מופשטות, ריבוי וסמיכות נגזרים — כך ש`פחת` מוצא `הפחת`,
`מבנה` מוצא `מבנים`, ו`מעמ` מוצא `מע"מ`. מגבלת שלוש אותיות בגזע היא מה שמונע
מ`פחת` להיגזר ל`פח`.

**חלוקה לפי סעיפים.** המסמכים כתובים כהיררכיה ממוספרת, והמספר הוא הדרך שבה
רואה חשבון מצטט. פיצול באמצע סעיף מייצר קטעים שאי אפשר לצטט, ואז בודק הציטוטים
פוסל תשובות טובות. ציטוט נראה כך:
`מהותיות בביקורת · קביעת מהותיות לדוחות בכללותם · סעיף 4(ב)`.

**קיבוע מזהים.** שאילתה שמציינת "תקן 27" מקבעת את תקן 27 לראש. סעיף
סמנטית-שכן על תקן 29 אינו כמעט-פגיעה, הוא תשובה שגויה.

**שיעורים בנתונים ולא בפרומפט.** מודל שנשאל מה שיעור המע"מ עונה מנתוני האימון.
השיעורים מתוארכים ב-`data/rates/rates.json`: עסקה ממרץ 2024 מקבלת 17%, אחת
מ-2025 מקבלת 18%, בלי שהמודל יידע אף אחד מהם. כל חישוב — מע"מ, פחת, מהותיות,
ערך נוכחי — רץ בפייתון, וכל כלי מחזיר את הקלטים לצד התוצאה כדי שהסוקר יראה איזה
שיעור הוחל.

**הסרת PII לפני האחזור, לא רק לפני המודל.** שאילתת האחזור יוצאת לספק האמבדינגס
המארח בדיוק כמו הפרומפט. המשתמש רואה מה יוסר לפני שהוא שולח.

**לוג ביקורת עמיד לשינוי.** כל רשומה נושאת את הגיבוב של קודמתה; עריכה שוברת את
השרשרת ו-`verify()` מדווח היכן. הטקסט הגולמי לא נשמר — רק הפרומפט לאחר ההסרה,
מזהי המקורות, וגיבוב הקלט. [SECURITY.md](docs/SECURITY.md).

## סטאק

Python 3.13 · FastAPI · Gemini / Anthropic · TypeScript · React · Vite

אין LangChain. האחזור, לולאת הכלים והצנרת הם כמאתיים שורות ישירות — קריא יותר
מהשכבה שהיה צריך להבין כדי לעקוף אותה, ובלי תלות שמשתנה כל חודש.

ספק המודל הוא שורת קונפיג: `LLM_PROVIDER=gemini|anthropic`. סכמות הכלים,
הפרומפט, בודק הציטוטים ורשומת הביקורת אינם תלויי ספק.

## מגבלות

נאמרות מראש ולא מוסתרות:

- **הקורפוס סינתטי.** שבעה מסמכי הדגמה בניסוח מעובד, לא נוסח רשמי. כל קובץ מסומן
  ככזה בכותרתו. ההנדסה אמיתית, טענת הדומיין מוגבלת.
- **32 שאלות שאני כתבתי, על קורפוס שאני כתבתי.** תוויות הזהב משקפות את הקריאה
  שלי בטקסט של עצמי. יש בזה מעגליות.
- **שלוש שאלות מחוץ לתחום.** שיעור הסירוב הוא אינדיקציה, לא מדידה.
- **אין מדידת איכות תשובה** — נמדדים אחזור, תקפות ציטוט וסירוב, לא נכונות
  מקצועית. זה דורש שיפוט של רואה חשבון.
- **אין אימות משתמשים**, הלוג הוא קובץ מקומי, והמפתחות ב-`.env`. פערי הפריסה
  מפורטים ב-[SECURITY.md](docs/SECURITY.md).
- **ההסרה היוריסטית** — מקטינה חשיפה, לא מבטלת. שם של אדם אינו מזוהה.
